## Task S: sentences against their marks, and the surgery arguments step by step

I redid each computation; where I could not, I say so.

**SU(N), N >= 4 (A.3j, [paper]).** `n = N²-1`, `H*(SU(N);Z) = Λ(x_3,...,x_{2N-1})`, so `x_3x_5 ≠ 0` in `H⁸(SU(N);Q)` and `8 < n` for N >= 4 (n = 15, 24, 35, ...). Rationally `[M,G/TOP]⊗Q = ⊕ H^{4i}(M;Q)`; `[M,G/TOP]` is finitely generated for finite M, so a multiple of a rational class with non-zero degree-8 part is a genuine normal invariant. N even: `n` odd, `L_n(1) = 0`, so every normal invariant is realised by a homotopy equivalence `f: X → M`. N odd: `n ≡ 0 mod 8`; subtracting `c^*θ(x)` at the top cell kills the obstruction and leaves the degree-8 class unchanged (the top cell carries only `H^n`). Then `p_1(X)=0` (since `H⁴ = 0`) and `L_2 = (7p_2 - p_1²)/45` gives `p_2(X) ≠ 0`, while `p(M) = 1` (parallelisable); any homeomorphism `X → M`, homotopic to `f` or not, carries rational Pontryagin classes to rational Pontryagin classes (Novikov), contradiction. Smooth: `G/O → G/TOP` is a rational equivalence, so a multiple lifts and the same X is smooth. The argument holds; the note says the "odd N" step and the lifting are written out, and they are. No published statement found (the notes say so; I found none either: unknown). Mark [paper] is right; the sentence in the chapter (line 61-64) says [paper].
