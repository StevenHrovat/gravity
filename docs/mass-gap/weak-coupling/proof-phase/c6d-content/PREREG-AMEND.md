# Amendment to the c5b pre-registration: a block-field content instrument that passes its photon control (c6d-content, 2026-11-22)

Status: **written before any run with the new instrument.** Amends `../c5b-content/PREREG.md` (referred to as "c5b"); c5b's files are untouched and all of c5b stays in force except where this file says otherwise. Claim levels as in `../../attempts/RULES.md`. CPU only, no GPU, nothing outside this folder written, nothing committed. Roles, not values.

## 0. Why
c5b measured lower bounds on R2 = Var(E[F|Phi_b])/Var(F) by held-out regression. Result: content at b = 2 only; zero at b = 4, 8. The photon control failed (U(1) at b = 4 gave 0.000 for the primary target, not above SU(2)), so the b >= 4 zeros are inconclusive (c5b NOTE 0). Two defects, both named in the c5b note:
1. **Features.** The photon's conditional mean E[F|Phi] is quadratic in the coarse fluxes (Gaussian conditioning: E[theta_p | Phi] is linear in the coarse plaquette angles, and F contains theta_p^2). Quadratic forms in the fluxes need (a) loops of several sizes, because 1 - cos of the flux through an R x T loop is, to leading order, the quadratic form sum over plaquette pairs of Theta_a Theta_b in its area, and (b) pair traces of neighbouring plaquettes in both relative orientations, whose difference is, to leading order, Theta_a . Theta_b (the cross term). c5b's features summed over orbits that merged all planes of one kind and all directions, and had loops up to 1x2 only, so cross terms at distance and plane-resolved weights were out of reach.
2. **Targets.** The plaquette scalar is mostly short-distance noise even for the photon. More long-wavelength weight: larger windows and smeared glueball-type operators.

## 1. New features (instrument "v2"; c5b's 108 orbit features are kept as the sub-instrument "v1")
All features are gauge-invariant functions of the block field, evaluated on the block lattice of the good blocking exactly as in c5b (same blocking, same cell-centre placement, same pooling over origins and cells). Each is **summed over a symmetry orbit and divided by the orbit size** (a mean), the orbit now respecting orientation.
* **(L) Plane- and orientation-resolved loops.** Fundamental traces of the planar R x T loops, R, T in {1, 2, 3} (nine shapes, R along the first plane axis), in all six planes; loop centre within 1.5 block spacings of the cell centre per axis (doubled coordinate at most 3). Orbit key: time-space planes: (shape, |t offset|, |offset along the plane's space axis|, sorted |offsets| of the two axes out of the plane); space-space planes: (sorted pair of (extent, |offset|) of the two in-plane axes, |t offset|, |offset| of the out-of-plane axis). Permutations and reflections of the three space axes are symmetries of the joint law and are merged; time is kept apart.
* **(P) Neighbouring plaquette pair traces, both orientations.** For plaquettes P_a (plane pi_1, base point x) and P_b (plane pi_2, base point x or x + e, e a positive unit step) the two gauge-invariant numbers `f+ = (1/2) Re tr(P_a T P_b T^dag)`, `f- = (1/2) Re tr(P_a T P_b^dag T^dag)`, T the link from x to x + e (T = 1 for the same base point). To leading order f+ - f- = -2 Theta_a . Theta_b. Pairs: same base point for pi_1 < pi_2 (15 plane pairs); neighbour pairs (base point of P_b at x + e) for pi_1 = pi_2 only, every positive direction (cross-plane neighbour pairs were dropped to keep the feature count at 700 columns in all: 108 of v1 and 592 new orbit keys; with them it was 1876). Orbit key: for each axis the tuple (in pi_1, in pi_2, direction-of-step times sign of the midpoint offset, |midpoint offset|), time axis apart, space axes sorted, plus the sign tag of f+/f-.
* The regression is c5b's (ridge in classes A, B, C chosen on the validation phase), run **twice on the same data**: on v1 (108 columns) and on v2 (v1 + L + P). v2 is the instrument; v1 is only an ablation that attributes any gain to the new features.

## 2. New targets (0++, gauge invariant, cell-centre placement; as c5b section 1 otherwise)
* **P2, P4**: c5b's plaquette scalar, windows 2 and 4 (continuity with c5b).
* **P8**: the plaquette scalar, window 8 (side 8 fine spacings, half of the 16 lattice).
* **Q4, Q8**: the smeared spatial 0++ operator: three steps of spatial APE smearing of the fine links (weight 0.5 of the spatial staples against the link, both signs, all spatial transverse directions, projection to the group after every step, all steps from the previous step's field), then the sum over the three spatial planes of the plaquette trace, averaged over the hypercube window of side 4 (Q4) or 8 (Q8).
* **Primary target of the verdicts: Q4** (window 4 = 1.4/sqrt(sigma) = 5.2 times 1/m at beta 2.3, the same window as c5b's P4; smeared so that the short-distance part is suppressed). P2, P4, P8, Q8 are reported, not used for verdicts, except the photon gate (section 3) uses Q4 and P8.

## 3. Photon control (fixed now)
U(1), beta = 1.1, 16^4, seed, sample sizes and sweeps exactly as c5b run C3 (110 / 40 / 80 configurations, every 3 sweeps, thermalisation 80, M = 1500), block weight w = 2, new instrument v2. c5b's pass condition (photon LB above SU(2)'s at b = 4) cannot gate a photon-first order, because the SU(2) run comes after. It is replaced by the following **absolute** gate; it is passed iff **all** hold at b = 4, w = 2:
* **(G1)** LB(Q4) - 2 err >= 0.01 and LB(P8) - 2 err >= 0.01 (that is 30 times the null noise of c5b, above every b = 4 number of c5b, and a quarter of the lowest b = 2 value that was resolved; chosen as "clearly non-zero long-wavelength content", not derived).
* **(G2)** instrument improvement: LB_v2(P4) - 2 err > 0.0031 (the c5b photon value of the same target and block, old instrument), with err the jackknife error of the new value.
* **(G3)** c5b's instrument gates (below, section 4) hold for the photon run.
If the gate holds, the c5b comparison is additionally reported after the SU(2) run (photon LB above SU(2) LB at b = 4 by 2 err_combined for Q4): reported, not gating; failing it while G1 to G3 hold is stated as "photon content present but not above SU(2)'s", which is not a defect of the instrument (the two theories are not at the same physical scale and SU(2) has its own content).
If the gate fails: **stop, SU(2) is not run**, and the failure is reported as a finding about the instrument with the next proposed fix.
The same run reports b = 2 and b = 8 and the decimation control (w = 0) for the photon. b = 8 has a 2^4 block lattice (c5b limitation, unchanged; with loops up to extent 3 the features wrap even more); it is reported, never gating.

## 4. SU(2) runs and verdicts (only if the photon gate holds)
Runs as c5b C1 (beta 2.3, seed 2301) and, if time allows, C2 (beta 2.5, seed 2501); same sizes; each at most 30 minutes, one process. Verdict rules are **c5b section 2.1 to 2.3 verbatim, with the primary target Q4 in place of P_2 and the new instrument v2**:
* LB >= 0.50 CONTENT-RICH; 0.10 <= LB < 0.50 CONTENT-PARTIAL; 0.02 <= LB < 0.10 CONTENT-SMALL; below that, or LB - 2 err below the class limit: the lower class, **INCONCLUSIVE** about the true R2 (never NEAR-NOISE; only the GPU part can say that). A class is claimed only if LB - 2 err is inside it.
* **Central question:** LB(Q4; beta 2.3, b = 8, w = 2) >= 0.10 (with the b = 8 lattice caveat). Also reported for beta 2.3, b = 4 (L sqrt(sigma) = 1.40).
* **Decimation control:** LB(w=2) - LB(w=0) > 2 err_combined for Q4 at b = 4 and 8, else "not resolved".
* **Instrument gates** (c5b 2.2, unchanged): selftest passed in this folder (alignment, planted R2, null target, plus the new checks: gauge invariance of the new features, agreement of the fast orbit sums with explicit shifts, targets); validation and test values agree: |R2_val - R2_test| < 0.03 + 3 err for Q4 at b = 2; plaquette mean drift between first and last third of the collection < 3 sigma.
* The exploratory residual proxy S(D) (c5b 2.3) is kept as is, not a verdict.
* c5b's readings of the consequences (c5b NOTE section 4) apply unchanged to the new verdicts: a resolved CONTENT class at b = 8 at beta 2.3 would say the block field carries measurable content at the conditional step L1; an INCONCLUSIVE does not move c5b's position (the GPU measurement of c5b section 4 stays the decisive one).

## 5. What the amendment does not change
Blocking, lattice, algorithm, seeds, run sizes, jackknife, held-out phases, the clamp at 0, and the rule that a regression bound never supports NEAR-NOISE. No result of the new instrument (except the instrument tests of section 4, which use synthetic data and one small lattice, and the machine-check that the code runs) was seen before this file was fixed.
