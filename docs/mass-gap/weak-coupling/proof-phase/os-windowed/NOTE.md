Route A of `m1-tools/PACK-OSDATA.md`, done in Lean. Three new modules under `formal/ProofPhase/OS/`

## What is proved

**Headline** (`OS/GapLoc.lean`):

```lean
theorem massGapLoc_of_UVTVBlockGap {T : Tuning} (ha : Tendsto T.a atTop (𝓝 0)) (h : UVTVBlockGap T) : MassGapLoc T
theorem massGapLoc_of_winBlockGap  {T : Tuning} (ha : Tendsto T.a atTop (𝓝 0)) (h : WinBlockGap T)  : MassGapLoc T
```

`UVTVBlockGap T`: one physical rate `m > 0`; every slab family of bounded physical extent has, from some level on,
`UVTVApprox T (m a_k) k (O.F k)`:
* approximants `g ℓ j` (bounded, measurable, on a time slab `[0, w_ℓ]` independent of the volume `j`) that are versions
  of `E[F | 𝓗_ℓ]`, with M1's σ-algebra conditions (`𝓗 ≤ 𝓕`, `Θ⁻¹𝓗 ≤ 𝓕`);
* M1's (B) term `≤ b_B ℓ` and (A) term `≤ b_A ℓ`, uniformly in the volume, `b_A, b_B → 0`;
* the block-level gap of the approximants: `|wcorr k j (g ℓ j) t| ≤ C_ℓ e^{-m a_k t}` while `2t + 2w_ℓ + 2 ≤ side`,
  with `C_ℓ` uniform in the volume.

So **M1's `OSData` hypothesis is gone**: the gap follows from M1's (A)/(B) bounds and the block-level gap alone,
through the repository's torus reflection positivity (`rp_gaugeMeasure`). No infinite-volume measure, no OS Hilbert
space, no `τ`-invariant block subspace.

## Differences from the pack's plan (simplifications)

* **No link reflection.** `τ_pos` (`wilson_rp_link`) is not used: the doubling argument only needs Cauchy–Schwarz for
  `Q` on the positive half, which also controls odd times.
* **No Hilbert space, no block invariance.** The spectral upgrade is done per vector by doubling on the window, and the
  density step is an explicit three-term estimate. The block gap is needed only for the approximants themselves, so
  the pack's "block invariance" point disappears, and the constants may depend on the block index.
* **Mean zero** is handled inside (`H_centred`); the decay hypothesis is the assembly's connected `wcorr`.
* **a.e. approximants**: the hypothesis is `g =ᵐ E[F|𝓗]` with `g` an everywhere-bounded version; `Q` only sees a.e.
  classes (`approx_le_of_UVTV`). No change to `UVTVReflect` was needed.
* The approximation error enters as `√ε`, so the decay rate is exact (no loss), and the prefactor `2` of `MassGapLoc`
  comes from `corr F 0 ≤ 2`.

## What is open (named hypotheses, all fields of `UVTVApprox`)

1. **Block-level gap of the approximants, uniform in the volume** (`decay`). This is the infrared input (the crossover
   / P4 side), now asked only for the versions `g ℓ j` of `E[F|𝓗_ℓ]`, with constants allowed to depend on `ℓ`.
2. **M1's (A) and (B) bounds uniform in the volume** (`hA`, `hB`, `b_A, b_B → 0`): Lemma UV-TV (paper level in
   m1-tools; Lean statementB and the influence modules give the forms).
3. **A slab-local bounded version of `E[F|𝓗_ℓ]`** (`slab`, `bdd`, `version`): needs `𝓗_ℓ` generated by block variables
   inside a time slab of fixed width, then Doob–Dynkin factorisation and clamping to `[-1, 1]`. Small; not done.
4. `a_k → 0` (the tuning), as in `bothOrdersLoc_of_torusDecayLoc`.

Not attempted: the other order of limits (`MassGapMFLoc`, spacing first). `level_gap` is volume-first only; the
spacing-first order would need the constants `C_ℓ`, `ε_ℓ` uniform in the level as well.
