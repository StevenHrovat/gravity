# §6, row E3: the constrained denominator and the Wilson-term cancellation (m1-tools, 2026-11-22)

Brief: row E3 of `M1-PLAN.md`: the denominator `D_X(W)` of the conditional step (the reference kernel integrated over
the fibre `{V̄_k = W}`) and the cancellation of its Wilson term against the numerator's, under the block constraint.
Read in full for this note: [V] pp. 357-361 ((1.2)-(1.22)); earlier reads of [V] pp. 355-356, 362-373 as recorded in
`NOTE.md` 1.2. Builds on `S6-START.md` (V1 from `[15]`). Claim marks as in `NOTE.md`.

## 0. Result in plain words

1. **Balaban's denominator argument carries over step by step, and two steps get simpler.** Expanding the reference
   kernel around the **constrained** minimiser `Û_0(W)` (V1) instead of the unconstrained `U_0`:
   * the term linear in the fluctuation vanishes by the same identity Balaban uses (`[15]` (170)/(178): the minimiser's
     current is orthogonal to every variation respecting the constraints), now with the block constraint on `Λ`
     included; what remains is the same boundary term [V] (1.5) with the same bound (1.6);
   * the quadratic form is Balaban's form restricted to a subspace (fluctuations with zero block average), so (1.7) holds
     as it stands; the Poincaré step (1.8) must be re-proved for the block-axial gauge (same argument, better constant);
   * the Gaussian normalisation counts fewer variables (the constrained directions are removed), which changes the
     constant `E_k(Λ)` of (1.10) by `½ d(g) log g_k^{-2}` per constrained coarse bond, **in numerator and denominator
     alike**, so it cancels in `N/D`.
2. **Result (E3):** for `W` regular on `Λ`,
   `D_X(W) = exp[-g_k^{-2} A(ζ_0, Û_0(W)) - Î(Û_0(W)) + Ê_k(Λ)]`, `|Î| ≤ O(1) log M |Λ| ≤ O(1) M^5`,
   with `Ê_k(Λ)` the constrained normalisation constant; `D_X` is analytic and non-zero in `W` (through `Û_0(W)`,
   `[15]` Proposition 9). Its Wilson term cancels exactly against the numerator's, because both are expanded around the
   same `Û_0(W)` (Balaban's (1.14)-(1.22) with `U_0 → Û_0(W)`).
3. **Status: paper, as a carry-over pinned to Balaban's equations** (section 1). Nothing new is needed; the new inputs
   are V1 (`[15]` Theorem 1, Proposition 9) and the Poincaré bound (1.8) for the block-axial gauge, to be re-proved by
   Balaban's argument.
   Not done: the analytic extension of these bounds to complex configurations (row E6) and the matched normalisations
   of `T̂'_k(X)` (row E5), where the per-bond constant above has to be tracked.

## 2. Where the constraint costs something

* **Normalisation:** `Ê_k(Λ) - E_k(Λ) = +½ d(g) log g_k^{-2} |Λ^{(k+1)}| + O(1)|Λ^{(k+1)}|`. The same change occurs in the
  numerator (it integrates the same constrained variables), so it cancels in `N/D`; in the final activity bound (1.89)
  only `O(1)` per coarse bond remains (row E5, where `ONE-STEP.md` 2.3 already estimated it as absorbed by Balaban's
  per-step entropy).
* **Nothing else:** the bounds (1.6), (1.7)-(1.9), (1.11) are unchanged or better.
